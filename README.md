# ذهب برايس — Zahab Price

إعادة تصميم موقع أسعار الذهب والفضة لحظياً في 37 دولة، مبني بـ Next.js.

- أسعار لحظية للذهب والفضة من خادم MCP الخاص بـ zahabprice.com (تحديث كل دقيقة)
- حاسبات: قيمة الذهب، البيع، الشراء، الزكاة، تحويل العيارات، ريال إلى جرام، تقسيط تابي وتمارا
- خزنة السبائك، أسعار العملات، أخبار الذهب والاقتصاد، ومساعد ذكي
- تصميم متوافق مع الموبايل وجاهز للعمل داخل WebView

## التشغيل محلياً

```bash
npm install
npm run dev
```

## متغيرات البيئة (اختياري)

- `ANTHROPIC_API_KEY` — لتشغيل المساعد الذكي بـ Claude. بدونه يعمل المساعد بقواعد مبرمجة.

## النشر

المشروع مربوط بـ Vercel: أي `push` على فرع `main` يُنشر تلقائياً على https://zahab-price.vercel.app
